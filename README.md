# Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Project Overview

This project demonstrates how **ServiceNow Flow Designer** can automate the procurement process for standard laptop requests, reducing manual work and improving the efficiency of IT procurement.
